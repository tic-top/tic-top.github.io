在开发 [py-alpha-lib](https://github.com/tic-top/py-alpha-lib) 的过程中，我积累了不少 PyO3 的实战经验。这篇文章总结了从零开始用 Rust 编写 Python 扩展的完整流程，以及一些容易踩的坑。

## 为什么选 PyO3

Python 的 C 扩展（CPython API）写起来繁琐且容易出错。ctypes 和 cffi 虽然更简单，但性能不如直接扩展。PyO3 提供了 Rust 到 Python 的零成本桥接，优势在于：

- Rust 的内存安全保证，不会出现 segfault
- 类型系统帮助你在编译期捕获错误
- 配合 maturin 构建工具，一条命令发布到 PyPI

## 项目初始化

```bash
pip install maturin
maturin init --bindings pyo3
```

这会生成一个标准的项目结构：

```
my_lib/
├── Cargo.toml
├── pyproject.toml
└── src/
    └── lib.rs
```

## 基本用法

### 导出函数

```rust
use pyo3::prelude::*;

#[pyfunction]
fn add(a: i64, b: i64) -> i64 {
    a + b
}

#[pymodule]
fn my_lib(_py: Python, m: &PyModule) -> PyResult<()> {
    m.add_function(wrap_pyfunction!(add, m)?)?;
    Ok(())
}
```

### 处理 NumPy 数组

这是量化计算中最常见的场景——处理大型浮点数组：

```rust
use numpy::{PyArray1, PyReadonlyArray1};

#[pyfunction]
fn cumsum(data: PyReadonlyArray1<f64>) -> PyResult<Py<PyArray1<f64>>> {
    let input = data.as_slice()?;
    let mut result = Vec::with_capacity(input.len());
    let mut acc = 0.0;
    for &val in input {
        acc += val;
        result.push(acc);
    }
    Python::with_gil(|py| Ok(PyArray1::from_vec(py, result).into()))
}
```

关键点：`PyReadonlyArray1` 提供了对 NumPy 数组底层内存的直接只读访问，无需拷贝数据。

## 性能陷阱

### 1. 不要频繁获取 GIL

```rust
// Bad: 每次迭代都获取 GIL
for i in 0..n {
    Python::with_gil(|py| { /* ... */ });
}

// Good: 一次获取，内部完成所有计算
Python::with_gil(|py| {
    for i in 0..n {
        /* ... */
    }
});
```

### 2. 释放 GIL 进行耗时计算

```rust
#[pyfunction]
fn heavy_compute(py: Python, data: PyReadonlyArray1<f64>) -> PyResult<f64> {
    let slice = data.as_slice()?;
    // 释放 GIL，允许其他 Python 线程运行
    let result = py.allow_threads(|| {
        slice.iter().map(|x| x.exp().sin()).sum()
    });
    Ok(result)
}
```

### 3. 避免不必要的内存分配

对于滚动窗口计算，使用环形缓冲区而非每次分配新 Vec：

```rust
fn rolling_mean(data: &[f64], window: usize) -> Vec<f64> {
    let mut output = vec![f64::NAN; data.len()];
    let mut sum = 0.0;
    for i in 0..data.len() {
        sum += data[i];
        if i >= window { sum -= data[i - window]; }
        if i >= window - 1 { output[i] = sum / window as f64; }
    }
    output
}
```

## 构建与发布

```bash
# 开发模式（快速编译，加载到当前 Python 环境）
maturin develop --release

# 构建 wheel
maturin build --release

# 直接发布到 PyPI
maturin publish
```

## 总结

PyO3 + maturin 的组合让 Rust-Python 扩展开发变得非常顺滑。对于计算密集型的 Python 库，这条路线在性能和开发体验之间取得了很好的平衡。
